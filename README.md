# ethically-robust

Code used for a project on discounting under moral uncertainty, with Stéphane Zuber.

To install dependencies, run `pip install -r requirements.txt`.
Make sure to create a virtual environment first, and activate it.

To update requirement files, use [pipdeptree](https://github.com/tox-dev/pipdeptree/):
```zsh
pipdeptree --python auto -f > requirements.txt
```
